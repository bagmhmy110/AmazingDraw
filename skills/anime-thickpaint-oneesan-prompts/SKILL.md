# Wuthering Waves 二次元半写实厚涂 · 御姐提示词系统

## 这是什么

一条固定骨架 + 七个独立词池的批量生产线。源自「8/26 那套」规则，已工程化。

**本文件是调度中心。** 词池、规则、脚本全在 `references/` 与 `scripts/` 里。

---

## 使用边界

- 全部内容用于**成年虚构角色（18+）**的图像生成。
- 年龄池固定 25-30 岁，不提供低龄选项。

---

## 固定骨架

```
{风格开头}
{年龄}{气质}，{发型}。
身着{服装}，{细节}，精致的东方面容。{性感动词}。{姿态}。
场景：{场景}。{光影}。
{质感句（部分风格才有）}
```

`{风格开头}` 由风格池决定，默认是 `Wuthering Waves style二次元半写实厚涂，竖屏构图。`

**丝袜点（可选，40%）**：`身着{服装}，{细节}，修长双腿穿着吊带丝袜，精致的东方面容。…`

## 硬性规则（不可违背）

1. 每条必须包含 **`精致的东方面容`**
2. 每条必须体现性感要素，高频使用：
   - `高开叉至大腿根部露出修长双腿`
   - `露出修长双腿`
   - `突出丰满胸部曲线`
3. **禁词**（命中即丢弃重抽）：
   ```
   九宫格 · 渔网 · 青涩 · 大波浪发型 · 机顶直闪 · 皮肤白皙细腻如瓷
   ```
   形容双腿时禁用「白皙」，只写「修长双腿」
4. **丝袜只允许「吊带丝袜」一种写法**，40% 概率加点
5. 人物气质统一**成熟御姐向**，不写少女感

## 组合逻辑

1. **独立随机**：六个池各独立选一个
2. **去重**：完整句子已存在则重抽
3. **违禁校验**：命中禁词或缺少必含词则丢弃重抽
4. **均衡分布**：五类服装按 `序号 % 5` 轮换

### 拼句函数

```python
STYLE_OPEN = "Wuthering Waves style二次元半写实厚涂，竖屏构图。"

def build(age, temper, hair, outfit, detail, sexy, pose, scene, light):
    return (f"{STYLE_OPEN}{age}{temper}，{hair}。身着{outfit}，{detail}，"
            f"精致的东方面容。{sexy}。{pose}。场景：{scene}。{light}。")
```

## 批量生成

**优先跑脚本**：

```bash
cd scripts
python generate.py -n 100 -o prompts.txt --json prompts.json --seed 2024
```

脚本内置：禁词校验、完整句去重、五类服装均衡轮换、丝袜 40% 加点、自检摘要。

### 可选参数

```bash
--category 传统旗袍,迷你旗袍   # 限定服装类别
--with-stockings 1.0          # 丝袜概率（0~1，默认 0.4）
--no-stockings                # 完全不加丝袜
--include-cultivation         # 启用修仙扩展池
--style guoman3d              # 风格：thickpaint / guoman3d / gamecg / guofeng
--seed 2024                   # 复现用
```

# 国漫 / 东方女性人像提示词系统

## 这是什么

一套从**词库选词 → 骨架填充 → 扩写成段**的完整提示词生产线。四个源文件已拆解重组为可执行的规则层 + 原始词库层。

**本文件是调度中心。** 词条、规则细节、范例全在 `references/` 里，按需读取，不要一次性全load。

---

## 使用边界

- 全部内容用于**成年虚构角色（18+）**的图像生成。
- 未成年角色（< 18 岁）**零身材描写**，服装限校服、衬衫、朴素裙装 —— 这条是硬边界，不因任何风格需求放宽。
- 除上述两条，词库全部内容按原样使用，不做删改与软化。

## 第一步：判断走哪条线

| 用户说 | 走哪条线 | 骨架文件 |
|--------|---------|---------|
| 二次元、厚涂、御姐、Wuthering Waves、国漫立绘、旗袍礼裙 | **线 B（主力）** | `references/05` §线B |
| 仙侠、古风、国风、汉服、敦煌、神女、女侠 | **线 C** | `references/05` §线C |
| 写实、CCD、旧照片、千禧年、学生、老师、生活流 | **线 A** | `references/05` §线A |
| 只要衣服、服装设定、高定设计、角色服装方案 | **线 D** | `references/05` §线D |
| 没指定 | 默认 **线 B**，25-30 岁成熟御姐 | — |

**四条线互不混用。** 一条 prompt 只走一条线，混线会让模型随机选一个，结果不可控。

## 第三步：生成

### 单条请求

1. 定线 → 读 `04` 过一遍禁词 → 读 `05` 拿骨架
2. 从 `01` / `02` 选词，按 `06` 的六原则校验协调性
3. 按 `07` 的五法扩写成段（线 B 100-180 字 / 线 A 120-200 字 / 线 C 250-420 字）
4. 输出【选中元素】+【完整提示词】两块
5. 用 `04` §六 自检清单过一遍

### 批量请求（要 20 / 50 / 500 条）

**优先跑脚本**，不要手写：

```bash
cd scripts
python generate.py -n 500 -o prompts.txt --json prompts.json --seed 2024
```

脚本已内置：禁词校验、完整句去重、`(服装×场景×姿态)` 三元组去重、五类服装均衡轮换、自检摘要。实测 500 条零违规零重复、五类各 100 条。

手写批量时，输出**省略【选中元素】块**，直接编号 + 正文，一行一条便于复制。

## 硬性红线（速查，详情见 `04`）

**每条必含：** `精致的东方面容`

**全风格禁词（出现即违规）：**
```
九宫格 · 渔网 · 丝袜 · 青涩 · 大波浪发型 · 机顶直闪 · 皮肤白皙细腻如瓷
```
另：形容腿时禁 `白皙`，只写"修长双腿"。

**二次元线专属：**
- 必须以 `Wuthering Waves style二次元半写实厚涂，竖屏构图。` 开头
- 用了这个开头就**不再写**"弱化轮廓线""2D动漫"（模型已内置）
- 不堆面部细节，否则跑成写实脸
- 全部成熟成年角色，1024×1536

**年龄边界：**
- 未成年 → 零身材/露腿描写，服装限校服衬衫朴素裙装
- 20-24 → 裙装可露腿
- 25-30 → 放开写，1-2 个高频句

## 文件之间的冲突（已裁决，别再纠结）

| 冲突 | 裁决 |
|------|------|
| 选词库有「丝袜&腿部配饰」分类，但"丝袜"是禁词 | **禁词优先**。该分类只取腿环/腿链/腿饰/中筒袜/过膝袜部分，需要包裹感时写"薄纱长袜" |
| 仙侠范例 31 条高频用 `皮肤白皙细腻如瓷`，但这是禁词 | **禁词优先**。范例只学**句式结构**，措辞改写为"肤若凝脂，肌肤细腻透亮" |

## 输出纪律

- 提示词正文**纯中文连续文本块**，不带 Markdown、不带换行分段、不带 `masterpiece, best quality` 这类英文尾巴
- 单条时给【选中元素】拆解便于用户微调；批量时省略
- 不解释"我为什么这么选"，直接给词。用户要的是能生图的 prompt，不是创作说明

| 禁词 | 说明 | 替换方案 |

| `九宫格` | 不做九宫格排版 | 直接删 |

### ⚠️ 冲突裁决：丝袜

选词库第八分类标题为「丝袜&腿部配饰（70种）」，但工作手册把 `丝袜` 列为全风格禁词。

**裁决：禁词优先。** 第八分类中所有含"丝袜"的词条视为**历史词条，不直接取用**。

- 需要腿部造型时 → 只取该分类里的**腿环 / 腿链 / 腿饰 / 中筒袜 / 过膝袜 / 堆堆袜**部分
- 确实需要腿部包裹感 → 写"薄纱长袜""透肤长袜""蕾丝袜口"，不写"丝袜"二字

### ⚠️ 冲突裁决：`皮肤白皙细腻如瓷`

`grok反推的仙侠提示词.txt` 的 31 条范例里高频出现这句，但工作手册明令禁止。

**裁决：以禁词表为准。** 范例文件用作**结构与句式参考**，不照抄其违规措辞。改写为"肤若凝脂，肌肤细腻透亮"。

## 三、性感元素规则

### 3.1 高频句池（多写）

```
露出修长双腿
突出丰满胸部曲线
高开叉至大腿根部
```

### 3.2 密度

| 批次类型 | 每句数量 | 覆盖率 |
|---------|---------|--------|
| 风情 / 写实批 | 1-2 个 | ≥ 80% |
| 二次元批 | 1-2 个（成熟角色放开写） | 全部 |

### 3.3 露腿分级（学生 / 老师 / 生活批专用）

按**服装类型**决定是否写"露出修长双腿"：

| 服装 | 是否写"露出修长双腿" |
|------|---------------------|
| 长裤 / 牛仔长裤 / 工装裤 / 喇叭裤 / 直筒裤 | ✘ 不写 |
| 短裙 / 短裤 | ✘ 不写 |
| 及膝裙 / 高开叉裙 / 筒裙等自然露腿裙装 | ✔ 才写 |

> 短裙/短裤不写，是因为服装本身已经露腿，再叠加"露出修长双腿"会冗余且把模型注意力带偏。只对**需要开叉才露腿**的裙装补这句。

## 四、角色年龄边界（硬边界，不可协商）

| 年龄段 | 身材 / 露腿描写 | 服装范围 |
|--------|----------------|---------|
| **未成年（< 18 岁）** | **一律零描写** | 限校服、衬衫、朴素裙装 |
| 18-19 岁 | 视服装渐增 | 日常休闲、校服可 |
| 20-24 岁 | 裙装可"露出修长双腿" | 全部日常 + 裙装 |
| 25-30 岁 | 放开写，1-2 个高频句 | 全部 |
| 27-28 岁 + 端庄线 | 回归裤装 / 及膝裙 | 职场、端庄 |

**执行方式：**
- 未成年角色 → 提示词中**不出现**任何胸、腰、臀、腿的形态描写，不出现高频句，不出现深 V / 开叉 / 紧身包臀 / 露腰
- 成年角色 → 按上表放开
- 不确定年龄时 → 默认按成年处理并显式写年龄（如"27岁成熟御姐"）

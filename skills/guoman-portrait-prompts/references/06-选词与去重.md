## 二、角色 × 场景强绑定（防违和）

**不同角色只配合理场景，不随机乱配：**

| 角色类型 | 只能用这些场景 |
|---------|--------------|
| 学生（18-19） | 教室、操场、校门口、放学路、图书馆、宿舍、自习室、文具店 |

> **反例（避免）：**"14岁初中生在挂满晾衣绳的楼道抱着东西跑" —— 角色与场景错位、悬浮感强。

## 四、批量去重三铁律

| # | 铁律 | 执行方式 |
|:-:|------|---------|
| 1 | **动作词去重** | 一个动词短语（"低头吃着方便面"）全批只出现一次。 |
| 2 | **三元组去重** | 用 `(年龄段/角色 × 场景 × 动作)` 做唯一键，撞了重采。 |
| 3 | **颜色/款式变体池** | 提示词相近时，衣服/头发改颜色或改款式错开。 |

### 组合逻辑（给脚本/agent 的硬性要求）

1. **独立随机**：从 年龄气质 / 发型 / 服装 / 性感动词 / 姿态 / 场景 各池独立随机选一个，拼接成句。
2. **去重**：维护已生成集合 `used`，若拼出的完整句子已存在则重新随机，直到不重复。
3. **违禁校验**：每生成一条即检查禁词表，命中则丢弃重抽（含必含词检查）。
4. **均衡分布**：五类服装按比例轮换，保证各类数量均衡。

```python
import random

def generate(n, pools, validate, build):
    used, out, tries = set(), [], 0
    while len(out) < n and tries < n * 50:
        tries += 1
        pick = {k: random.choice(v) for k, v in pools.items()}
        line = build(**pick)
        if line in used or not validate(line):
            continue
        used.add(line)
        out.append(line)
    return out

def validate(line):
    BAN = ["九宫格","渔网","丝袜","青涩","大波浪发型","机顶直闪","皮肤白皙细腻如瓷"]
    if any(b in line for b in BAN):
        return False
    if "精致的东方面容" not in line:
        return False
    if "白皙" in line and "双腿" in line:
        return False
    return True
```

## 五、比例控制（防题材偏科，血泪教训）

- 某类动作/道具占比要**刻意压制**。**真实反例**：一次学生批让"方便面"类占了 28%，观感极差。此后吃食类动作压到 **≤6%**，且拆成不同食物（冰棍/汽水/包子/奶茶/烤串…）。
- 角色年龄段建议错开分布（如初中/高中/大学 30%/35%/35%），不要一边倒。
- 五类服装线（旗袍/迷你旗袍/迷你礼裙/包臀裙/长礼裙）各占约 1/5；轮换方式 `类别 = 序号 % 5`。

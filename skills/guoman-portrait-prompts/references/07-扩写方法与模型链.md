# 扩写方法论 · 从标签到画面

> 核心动作：把**关键词**从"标签"扩写成"画面描述"。这是本 skill 与"贴标签式 prompt"的分水岭。

---

## 一、扩写五法

| # | 手法 | 示例 |
|:-:|------|------|
| 1 | **具象化** | "清冷御姐" → "一位25-29岁的清冷御姐，气质冷艳疏离，眉眼疏离，自带高级清冷感" |
| 2 | **加感官细节** | "胶片写真" → "胶片写真风格，富士NC胶片质感，颗粒细腻，色调偏暖复古，带有自然的曝光宽容度" |

## 二、扩写三原则

1. **连贯成段**：所有扩写内容必须连贯成一段完整的描述，不是关键词罗列，而是有逻辑的画面叙述。
2. **篇幅控制**：扩写后总长度控制在 **150-300 字**之间，信息密度高但不冗余。
   - 二次元线可压到 **100-180 字**（模型对长 prompt 敏感度低，简洁反而稳）
   - 仙侠立绘线可到 **300-420 字**（服装细节需要展开）
3. **信息分层**：先主体（人）→ 再服饰 → 再姿态 → 再镜头 → 再背景 → 最后氛围收束。这个顺序与模型注意力权重吻合。

---

## 三、扩写的反面清单

| 反模式 | 为什么不行 | 改法 |
|--------|-----------|------|
| `美女，漂亮，性感，高清，8K` | 纯形容词堆砌，模型无法定位具体形态 | 换成具体部位 + 具体形态描述 |
| `一个女孩站在海边` | 无镜头、无光、无材质 | 补全：镜头距离 + 光线方向 + 服装材质 + 风/水互动 |
| 同一句里塞三个矛盾风格 | 模型会随机选一个，结果不可控 | 一条 prompt 只走一条风格线 |
| 结尾加 `masterpiece, best quality` | 中文模型里是噪声 | 删，改用具体质感词 |
| 用"很""非常""极其"堆强度 | 中文 prompt 里强度副词几乎无效 | 用具体比较级替代（"垂至腰际""开叉至大腿根部"） |

## 四、三条线的扩写侧重

| 线 | 扩写重心 | 字数 | 特别要求 |
|----|---------|------|---------|
| A 写实 CCD | **质感与真实感** | 120-200 | 质感词必须堆足，结尾规避句必带；人物描述反而要克制 |
| B 二次元厚涂 | **服装性感细节 + 姿态** | 100-180 | 面部只写"精致的东方面容"，不展开五官 |
| C 古风仙侠 | **服装结构与材质层次** | 250-420 | 配色/材质/纹样/腰肩/配饰逐层展开 |
| D 国漫服装设计 | **纯服装七要素** | 200-350 | 不写人，只写衣服；收尾用固定高级感句 |

## 五、输出格式（单条请求时）

```
【选中元素】
- 画幅：9:16 竖屏
- 画风风格：xxx
- 人物形象：xxx
- 发型：xxx
- 发饰：xxx（或"无"）
- 妆容：xxx
- 服装：xxx
- 丝袜腿部：xxx（或"无"）
- 姿势：xxx
- 镜头位置：xxx
- 背景场景：xxx

【完整提示词】
（扩写后的一段完整提示词，可直接用于生图）
```

> **批量请求时**（用户要 50 条、500 条）：省略【选中元素】块，直接输出编号 + 提示词正文，一行一条，便于复制进脚本或表格。

## 六、微调响应

用户追加要求时，只改被点名的那一项，其余保持不动：

| 用户说 | 改什么 |
|--------|--------|
| "把场景换成海边" | 只换背景场景 + 相应光影，其余全保留 |
| "妆容淡一点" | 只换妆容词条，不动服装发型 |
| "再来十条不一样的" | 换姿态 + 场景 + 服装组合，风格线与人物气质保持一致 |
| "太露了" | 降性感级别（重度→中度→轻度），删减高频句数量 |
| "换成古风" | 整条重走 C 线，不要在原现代 prompt 上打补丁 |

## 七、模型链（ComfyUI，二次元线实测配置）

| 项 | 值 |
|----|-----|
| **基座模型** | `Krea2\moodyAmateurMixKrea2_v10.safetensors` |
| **LoRA** | `胸尺寸 breast_size_krea2_loraholic` → **2.0**<br>`Krea2-realism_engine_v2_轻量` → **0.4** |
| **CLIP** | `qwen3vl_4b_fp8_scaled`（type=krea2） |
| **VAE** | `qwen_image_vae` |
| **采样** | steps=10, cfg=1.0, euler, simple, denoise=1.0 |
| **分辨率** | 1024×1536（竖屏） |

**工作流节点约定：**
- `164` = 提示词 CLIPTextEncode
- `156` = EmptyLatentImage（宽高）
- `153` = Seed（rgthree）
- `305` = SaveImage

> 其他模型（MOSS-Image、SDXL、Flux 等）可直接复用提示词正文，但采样参数与 LoRA 权重需自行重调。

## 四类语料共同的提示词语法

最稳定的写法不是短关键词堆叠，而是一段可直接交给摄影或生图模型执行的完整描述：

`摄影媒介与开头 -> 成年主体身份 -> 五官发型体态 -> 服装配饰 -> 姿势动作 -> 前景 -> 中景 -> 背景 -> 构图机位 -> 镜头焦段 -> 灯光 -> 色彩 -> 材质真实感 -> 氛围用途`

使用具体名词和空间关系。写清楚什么物件接触什么位置、光线从哪里来、哪些区域清晰或虚化、面料如何垂坠、主体位于画面哪里，以及哪个前景物件引导视线。

## 性感语气与视觉强度

四份语料并不是普通职业照或清淡人像，而是带有明显成人性感、挑逗和情趣时尚倾向的写实摄影提示词。改写时应保留以下层次：

- **服装信号**：低胸、深V、露肩、露背、开衩、短裙、贴身剪裁、半透明面料、蕾丝、缎面、皮革、丝袜、吊带、紧身制服、头纱、发冠和珠宝。

- **灯光信号**：暖色床头灯、夜间办公室灯、霓虹反光、柔和侧光、背光轮廓、皮肤高光、缎面反光和暧昧阴影。

不要把原始性感内容自动弱化为普通职业照、保守穿搭或清淡日常写真。需要保留裸体或明显裸露时，将其写成21岁成年人的成人艺术写真或情色时尚摆拍，并保留原始的性感意图、构图和摄影语言。

## 各文件的风格特征

### `制服sex2.txt`

- 91条提示词都使用紧凑、连续的成人写真编辑结构。
- 主体通常是身份稳定的中国成年女性，只改变服装、姿势、环境或镜头。
- 常见空间包括中式婚房、酒店套房、亭台、办公室、诊所和卧室。
- 服装连续性很重要，包括秀禾服、婚纱、头纱、发冠、丝袜、皮革装饰、护士服、办公室套装和夏装。
- 先写姿势名称，再用具体的四肢位置和身体几何说明姿态。
- 技术尾句常使用35mm或50mm、中长全身或中景构图、自然皮肤纹理、细小绒毛、织物纹理、布料张力、垂坠褶皱、首饰高光和接触阴影。

### `001.txt`

- 500条提示词普遍较长，物件密度高。
- 常见开头是“写实摄影，一位21岁成年女性……”，随后展开为带有抓拍感的生活场景。
- 前景物件非常重要，包括手机、包、饮品、鲜花、产品包装、相机、头盔、工具、家具、金钱、食物和招牌。
- 将前景、中景、背景分开描写，加入虚化、反射、路人、建筑和屏幕等景深信息。
- 常用低机位、中景、特写、肖像、自拍和手持纪实构图，也常用轻微倾斜、颗粒、运动模糊、自然噪点和不完美曝光模拟日常拍摄。
- 通常会明确写出色彩组合，并将色彩与场景材质联系起来。

### `汉服脱衣舞_v5.txt`

- 120条提示词组成一个重复使用的舞台图库。
- 主要结构为中国舞蹈灵感、颜色明确的服装、黑色盘发、具体发饰、一个清晰姿势、木质舞台、柔和舞台光和85mm全身摄影尾句。

- 常见花卉或植物景片包括杏花、竹、梅、莲、兰、木兰、柳、银杏、菊、紫藤、芦苇和山茶。

### `杂图.txt`

- 主要使用正面、侧面、低机位、背面或正侧面写实摄影语言。
- 常见环境包括体育场、竞技场、健身房、舞台、庭院和室内摄影棚。
- 重复出现蓝色垫子、观众、泛光灯、横幅、聚光灯、头带、手镯、项链、辫发、强烈灯光、明亮自然光、浅景深、高分辨率和水印。

## 镜头与成片质感词汇

只使用用户要求或源提示词支持的机位和镜头组合：

- 35mm：适合动态全身、环境人像、低机位、公共空间和街拍。
- 50mm：适合中景肖像、镜面场景、办公室、卧室和自然视角。
- 85mm：适合舞台、汉服、全身肖像、压缩背景和控制感较强的编辑风格。
- 低机位：突出身材线条、舞台存在感、权威感、体育场和时装姿态。
- 正面或平视：突出直视镜头、对称构图和商业肖像。
- 侧面或背后三分之四：突出轮廓、背部线条、回眸和姿势几何。
- 俯拍或高机位：适合床面、地面、瑜伽动作和受控构图。

## 最终检查

批量转换或创作后确认：

1. 非空条目的数量和原始顺序保持不变。
2. 所有年龄均已写成21岁或21岁成年人。
3. 没有残留未成年人、儿童、少年、学生年龄或低龄性化词语。
4. 没有因为难以解析而删除重要的场景、动作、服装、道具或摄影细节。
5. 输出为UTF-8纯文本，可以直接作为生图提示词文件使用。
6. Skill正文、参考文档、提示词和解释均使用中文；品牌名、招牌文字、镜头型号和文件名可按原样保留。

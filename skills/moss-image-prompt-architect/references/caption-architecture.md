# Caption 架构 — 人物／角色中心图像的正文写法

> 默认输出模式。适用于：人像、角色 LoRA 演示、生活场景、日常摄影、多人场景、产品摄影、绘画、
> 插画、建筑、以及无精确位置约束的复杂画面。

---

## 段落架构（灵活指南，不是填空题模板）

### 第 1 段 — 确立「这是什么图」与「相机与场景的关系」

一次性交代：

- 摄影／插画风格、画面类型（什么性质的瞬间）
- 相机距离与角度
- 取景与裁切
- 主体动作
- 主导光线

只在**真正相关**时才点名光学效果（例如背景虚化弱到什么程度会改变可读性）。
**禁止**在多个提示词之间复用同一个开篇模板——每次换起手方式。

### 第 2 段 — 主主体（Lead subject）

顺序：

1. 先给**相对画面的位置**，以及相对他人的位置
2. 视觉相关的身份与外观
3. 服装：具体的版型／颜色／材质，不是"好看的裙子"
4. 姿态、头／脸朝向
5. 脸上的表情（可见的那种）
6. 与紧邻环境的互动

角色识别必须保留：用户已定义人物／角色设计或已指定 LoRA 时，
**不得**虚构与之冲突的新面容或新身份。

### 第 3 段起 — 每个重要的额外主体独占一段

当空间关系重要时，一个主体一段。每段必须写：

- 相对主主体的距离／位置
- 可见服装
- 动作
- 视线
- 与道具或彼此的接触
- 清晰的角色分工

**绝不**把两个人的手或动作混为一谈（"一只手扶着她的肩，另一只拿着杯子"→ 必须说清是谁的哪只手）。
当两个主体不可分割时（例如紧紧相拥），合并成简洁的共同描述是允许的。

### 末段 — 环境与背景

在主体确立之后再写：

1. 环境与背景
2. 自然光的细化
3. 对焦与景深层级
4. 质感
5. 构图的最终收束

只写**属于这一帧故事**的细节，不是随机道具清单。

---

## 人物与动作精确性

- 主要人物按**对画面的重要性**排序：前景主主体 → 互动对手 → 次级／远处人物。
  当视觉叙事需要时，允许打破该顺序。
- 每个重要角色出场时，给出相对相机、相对他人、相对相关物品的**可理解位置**。
  只有距离会改变构图时才写距离；普通肖像不强行塞进测量值。
- 年龄区间与其他身份线索：**仅**在用户指定或视觉上重要时描述。
  头发、衣物、面料、配饰、可见特征要具体；已确立的角色 LoRA 不强行堆砌冗长五官清单。
- 当动作重要时，交代躯干朝向、头部朝向、视线方向。
- 当手是主动作执行者时，指明是哪只手在拿／碰／施加／打开／伸向哪个物体，
  并让物体的位置与接触关系可信。
- 只写**可见且相关**的重要肢体与重心分布。紧裁切的特写里不得声称展示了脚、全身站姿或隐藏肢体。
- 多人互动：动作与身体部位必须归属正确的人；在引入时立刻交代邻近关系、朝向、接触、角色分工。
  分开成段有助于读者追踪。
- 不刻板地逐一罗列每根手指、每件衣饰、每个关节——只选到足以无歧义渲染这一瞬间的细节。

---

## 提示词密度与真实感

- **精确锁定主动作**：捕捉一个可辨认的瞬间，而不是一整段事件序列。
  关键道具要可辨识并物理就位。
- 次级细节只在能强化地点、自然感或故事时使用。简短的用户想法允许经过判断的艺术选择，
  但**不授权**任意编造背景故事或装饰性杂物清单。
- 用观察性细节代替空洞赞美、重复的质量词、被用滥的社论腔。
  普通环境可以有生活痕迹而不是一尘不染，但不必把脏乱和瑕疵强塞进每个场景。
- **跨输出变化**句式开头与镜头设计。避免这些惯性默认：白 T 恤、梳妆台、柔和的窗光、咖啡馆、
  一模一样的腰部以上构图。
- 不设全篇统一字数或段落数。信号密度高的短提示词，胜过稀释了主视觉目标的冗长版本。

## 自适应规则

| 情况 | 处理 |
|:--|:--|
| 仅可见且相关的部位 | 才描述解剖、配饰、肢体、鞋履、服装。头肩特写不写腿，不猜不可见的手的位置 |
| 单一主体 | 不必发明额外人物，也不必凑满四段 |
| 广角场景 | 位置与距离写清楚 |
| 头肩特写 | 侧重面部朝向、表情、头发、衣领与其邻近环境 |
| 无摆拍日常 | 偏好可信的不完美瞬间、偶然出现的物件、正常的室内／街灯光、真实的动作 |
| 指定风格（动漫／数字绘画／渲染／插画／时尚社论／棚拍） | 使用该媒介的语言，不强行拉到照片写实；**族裔仍为亚洲人**，动漫／插画同样适用 |
| 非人物图像 | 走另一条流程：视角／构图 → 主主体或物件 → 材质／功能／视觉特征 → 场景／语境 → 光线与最终视觉组织。**不得**发明一个人 |
| 情绪与内心状态 | 只能通过可见特征或肢体语言表达，不写无据的内心想法或长篇背景故事 |
| **任何有人物的画面** | 人物族裔**固定为亚洲人**（中国／日本／韩国／其他亚洲族裔），并显式写出可见特征；用户明确指定其他族裔时除外 |

## 族裔落地（全局硬约束）

**画面中的每一个人物都是亚洲人：中国人、日本人、韩国人，或其他亚洲族裔。**

这是一条**既定前提**，不是需要论证的推断。用户没提族裔时，默认亚洲人；用户提了其他族裔才改。

### 必须做到

- **每条提示词都要显式写出族裔**，不能靠模型自己猜。至少一处明确的国家／族裔词。
- **多人场景全部适用**：前景主体、互动对手、背景路人、只露出背影或一只手的人，都要落到亚洲人。
- **族裔与场景要对得上**：中国的菜市场配中国面孔，日本的钱汤配日本面孔，首尔的写字楼配韩国面孔。
  diaspora 场景（伦敦的亚裔、纽约的亚裔）同样成立，但要写出亚裔特征而非默认白人。
- **用可见特征落地**，不要只贴标签。族裔在画面里是通过这些被看见的：

| 维度 | 可写的具体内容 |
|:--|:--|
| 肤色 | 暖象牙色、浅橄榄色、蜜色、深古铜色——给具体色阶，不写"晒黑" |
| 眼型 | 内眦赘皮、眼窝浅、单眼皮、低褶双眼皮、眼尾略上扬 |
| 发质 | 粗硬直发、细软直发带蓝黑光泽、厚而微卷、漂成枯黄橘色、发根见白 |
| 发色 | 乌黑、蓝黑、暖调深棕、染成红棕、花白 |
| 面部结构 | 颧骨平而宽、鼻梁低、人中短、下颌方正、脸型偏鹅蛋 |
| 妆造线索 | 与地域相符的具体做法（如日式薄透底妆配卧蚕、韩式水光肌配平直眉、中式自然眉配哑光唇），不写笼统的"亚洲妆容" |

### 禁止

- ❌ 只写"一个亚洲女性"就收工——**族裔必须可被看见**，不能只是一个词
- ❌ 写出任何非亚洲人的面孔、肤色、发质（硬约束）
- ❌ 把族裔特征堆成一段人类学清单——像写别的一样，**挑 2–3 个真正相关的**，融进外观描述
- ❌ 用族裔去暗示性格、阶层或智力（特征只描述外观）

### 密度控制

族裔描述**不超过外观段的三分之一**。它是身份的一部分，不是提示词的主角。
一条写得好的人像，读者从肤色、眼型、发质里自然读出"这是中国女性"，而不是被通知"这是中国女性"。

## Caption 输出格式

- 只返回打磨过的**中文散文**，必要时分段。
- 描述具体的可见内容，而不是写给模型的解释。
- 不要输出 `{"caption":"..."}` 这类包裹层——在官方流程里那只是内部草稿，编译后是纯文本。
- Caption 模式**不使用坐标**。
- **可见文字保持原语言**：招牌、海报、书脊、屏幕上的字，原文照抄，不翻译。
- 摄影与影像术语（如 35mm、浅景深、逆光、反光板）用中文常规译法即可，型号类专有名词可保留原文。

# NSFW Prompt Templates — Asian JAV Style

## 这是什么

一套按**组装顺序**排布的 14 模块 NSFW 提示词词库，源自
[ShuaiHui/nsfw-prompt-templates-asian](https://github.com/ShuaiHui/nsfw-prompt-templates-asian)。
词条已英文化、场景化，并标注搭配禁忌。

**本文件只是索引。** 术语、词条、组合规则全部在 `references/` 里，按需读取。

## 使用边界

- 全部内容用于**成年虚构角色（18+）**的图像生成。
- 不用于现实具体人物（含公众人物）的性化图像；不含未成年外貌与未成年年龄暗示。
- 除此之外，词库全部内容按原样使用，不做删改与软化。

## 组装顺序（源自仓库 README）

```
[场景+主题] + [景别+视角+设备] + [裸露状态] + [服装状态] + [光影氛围]
+ [姿势动作] + [表情眼神] + 选读（风格/妆容/发型/瑕疵/纹身/道具/人格）+ [画质强化]
```

- 方括号内的槽位每次各取 1 个；选读部分每次取 3-5 个。
- 具体词条、联动关系、禁止组合见各模块文件。

## 读取建议

词库合计约 560KB，**不要整份读**。

1. 多数文件开头有 `## 📋 索引` 段，先看索引再跳到目标小节。
2. 用 `read` 的 `offset` / `limit` 只读目标小节。
3. 一次任务通常只需 4-7 个模块：必读槽 + 若干选读槽。
4. 需要成品参考时读 `00-范例.md`。

## 说明

词库是**料**，不是**语法**。提示词最终用什么句式（标签流 / 散文流）、多长、要不要负面词，
由出图模型和用户当下的要求决定——这些不在本词库内规定。

# 国漫服装装配 + 仙侠立绘成稿

## 这是什么

两条生产线，共享同一套词库：

- **线 D · 服装装配** — 只要衣服不要人。七槽装配产出角色服装设定。
- **线 C · 立绘成稿** — 人 + 衣并重。六句骨架产出完整人像提示词。

**本文件是调度中心。** 词条与规则在 `references/`，结构化索引与可执行脚本在 `assets/` 与 `scripts/`，按需读取，不要一次全 load。

---

## 词库是什么样（先看这个）

服装有**两套零件**，合并后才够密度：

**第一套 · 七槽骨架**（`references/01-服装词库-1100条.txt`）

1100 条组合词，号段 0424-1523，每条固定七槽：

```
{配色}，{材质}，{纹样}，{袖型}，{裙装结构}，{腰部}，{肩部}
```

逐槽词值数：配色 20 · 材质 30 · 纹样 30 · 袖型 30 · 裙装结构 30 · 腰部 30 · 肩部 30。

**第二套 · 范例结构层**（`references/02-仙侠范例31条.txt` → `scripts/example_lexicon.py`）

从 31 条范例里抽出来的高频组件，共 10 层 184 条：

| 层 | 作用 | 范例里的存在感 |
|----|------|--------------|
| 上装结构 | 深V低胸 / 交领紧身 / 紧身胸甲 | 26/31 条有 |
| 肩部 | 龙鳞状护肩 / 羽翼状护肩 / 露肩 | 7 种 |
| 装饰纹样 | 金属浮雕花纹 / 晶体刺绣 / 璎珞 | 16 种 |
| 腰饰 | 宽阔织锦腰带 / 复杂腰封 | 10 种 |
| 配饰 | 璎珞项链 / 多层宝石吊坠 / 翠玉 | 10 种 |
| 发饰 | 凤凰冠 / 龙鳞火焰冠 / 花叶发饰 | 21 种 |
| 额饰 | 红色印记 / 银色细链宝石额饰 | 10 种 |
| 耳饰 | 长款流苏耳坠 / 圆形镂空耳环 | 10 种 |
| 颈饰 | 金色镂空颈环 / 银色花朵颈环 | 8 种 |
| 光感收束 | 丝绸与金属的高光质感 | 28/31 条有 |

**只用七槽会空，只用范例层会散。** 合并后的服装句长这样：

> 齐胸襦裙，上身为轻薄纱质交领设计，天青与湖蓝配色，柔光绸材质，胸前与肩部装饰银色云纹刺绣与不对称护肩，流云纹刺绣沿着衣缘蔓延。花瓣袖口垂落，宽阔织锦腰带束住腰线，星辰腰链压住整体轮廓，璎珞项链在光里点出冷亮的一笔，整体布料在柔光下泛着丝绸般的光泽。

**七槽里的 `肩部` 与范例层的 `肩部` 是两回事**：七槽的是「花瓣肩饰/云肩/披帛」这类装饰，范例层的是「龙鳞状护肩/羽翼状护肩」这类护甲。脚本用范例层，七槽的肩部槽保留在装配里但不出现在句子中。

**没有独立的分类词条。** 不存在 `[上装结构]`、`[配饰]`、`[鞋履]`、`[服装边饰]`、`[动态]`、`[色彩]` 这些词库分类 —— 上装/配饰/发饰全部来自范例层，鞋履不出现。

人物侧（面部 / 发式 / 姿态 / 场景 / 光影）是 skill 自带的写作层，不依赖任何词库。

## 使用边界

- 全部内容用于**成年虚构角色（18+）**的图像生成。
- 未成年角色（< 18 岁）**零身材描写**，服装限校服、衬衫、朴素裙装 —— 这条是硬边界，不因任何风格需求放宽。
- 除上述两条，词库全部内容按原样使用，不做删改与软化。

## 第一步：判断走哪条线

| 用户说 | 走哪条线 | 怎么给 |
|--------|---------|--------|
| 只要衣服、服装设定、角色设计图、高定方案 | **线 D** | 跑 `combo`，或读 `04` 七槽公式手装 |
| 仙侠、古风、仙女、神女、宫廷、女侠、妖姬、新中式人像 | **线 C** | 跑 `portrait`，或读 `04` 六句骨架手写 |
| 给了具体服装元素（"墨黑配色 + 凤凰羽袖"） | **线 D** 锁定槽位 | `combo --color 墨黑与暗金 --sleeve 凤凰羽袖` |
| 要 20 / 50 / 500 条 | **线 C 批量** | 跑 `batch`，脚本已内置去重与质检 |
| 没指定 | **线 C**，仙侠调性 | `portrait --tone 仙侠 --scene 云海` |

**两条线不混用。** 线 D 里不写人物面部，线 C 里不省服装结构。

## 第二步：五个调性（这是本 skill 的核心约束）

词库给的是零件，调性给的是**零件兼容性**。没有这层约束，随机装配会撞出「暗黑战甲 + 月白配色 + 清澈温柔眼神」这种废稿。

| 调性 | 配色倾向 | 材质倾向 | 气质基调 |
|------|---------|---------|---------|
| 仙侠 | 月白·冰蓝·霜蓝·浅紫 | 纱·丝·绫，轻盈通透 | 清冷、飘逸、疏离 |
| 宫廷 | 朱红·绛红·孔雀蓝·金 | 锦·缎·绒，厚重有垂感 | 雍容、矜贵、威仪 |
| 战斗 | 墨黑·赤红·深蓝·青灰 | 皮革·金属·紧实织物 | 凌厉、飒爽、警觉 |
| 暗黑 | 紫黑·酒红·墨绿·暗银 | 薄纱·丝绒·幻彩 | 神秘、冷艳、压迫 |
| 新中式 | 月白·青灰·淡金·香槟 | 真丝·缎面·混纺 | 现代、利落、松弛 |

**调性决定的不只是配色**，还包括七槽全部取值、眼神、气质、肤质、唇色、发饰、颈饰、姿态、动态、光影、氛围。完整对照表在 `references/05-调性联动表.md`，脚本实现见 `scripts/tone_profile.py`。

**五个调性已覆盖词库全部 170 个词值**，`verify` 子命令可随时校验。

## 第四步：生成

### 单条请求

```bash
# 线 C：立绘成稿
python scripts/promptforge.py portrait --tone 暗黑 --scene 废墟 --leg bold --seed 11 --pick

# 线 D：服装装配
python scripts/promptforge.py combo --seed 7 --tone 仙侠 --pick

# 查词
python scripts/promptforge.py lookup --list
python scripts/promptforge.py lookup --slot 袖型
python scripts/promptforge.py lookup --slot 纹样 --kw 凤凰
```

手写时按 `04` 的骨架填，从 `05` 取调性词池，用 `06` 过一遍自检。

### 批量请求（要 20 / 50 / 500 条）

**优先跑脚本**，不要手写：

```bash
python scripts/promptforge.py batch -n 500 -o prompts.txt --json prompts.json --seed 2024
python scripts/selfcheck.py prompts.txt --strict
```

脚本已内置：禁词校验、完整句去重、`(风格款×场景×姿态)` 三元组去重、五调性均衡、跨条句式重复率检查。实测 500 条零违规，第二句重复率 7%（阈值 30%）。

### 词库改动后

```bash
python scripts/build_index.py      # 重建索引
python scripts/promptforge.py verify   # 校验调性池是否仍在词库内
```

**改了词库必须跑这两条**，否则调性池里会留着词库已删掉的词，产出的提示词与词库对不上。

## 硬性红线（速查，详情见 `06`）

**全风格禁词（出现即违规）：**
```
九宫格 · 渔网 · 丝袜 · 青涩 · 大波浪发型 · 机顶直闪 · 皮肤白皙细腻如瓷
```
另：形容腿时禁 `白皙`，只写"修长双腿"。

**拼接病句（词库自带的坑，务必避开）：**

| 坑 | 症状 | 正确写法 |
|----|------|---------|
| 槽值自带后缀 | 「月白与银灰配色**配色**」 | 索引已剥成裸词，拼装时补一次后缀 |
| 袖型自带结构语义 | 「长袖自然垂落随动作垂落」 | 袖型只并列，不接动词 |
| 发色+发式重复 | 「红棕色的头发长发半挽」 | 短句版发式：去掉「长直发」前缀 |
| 场景自带情绪词 | 暗黑撞「阳光明媚的庭院」 | 场景本体中性，情绪按调性注入前缀 |
| 光影不搭 | 仙侠 +「戏剧性顶光」 | 按 `(调性, 场景)` 查 `LIGHT_OVERRIDE` |
| 动态撞服装句 | 「丝绸自然垂坠」接「衣料垂坠…」 | 脚本已自动换词 |

**年龄边界：**
- 未成年 → 零身材/露腿描写，服装限校服衬衫朴素裙装
- 20-24 → 裙装可露腿
- 25-30 → 放开写，1-2 个高频句

## 露腿分级（线 C 的 `--leg`）

| 级别 | 写法 | 适用 |
|------|------|------|
| `none` | 完全不提腿 | 保守需求、宫廷正装 |
| `mild` | 「裙裾下露出修长双腿的轮廓」类，只给线条 | 默认，绝大多数场景 |
| `bold` | 「裙摆高开叉至大腿根部，露出修长双腿」 | 明确要求性感时 |

## 微调响应表

| 用户说 | 改什么 |
|--------|--------|
| "场景换成海边" | 只换 `--scene`（需先在 `tone_profile.py` 的 `SCENE_BASE` 加场景 + 补 `LIGHT_OVERRIDE`） |
| "妆容淡一点" | 只换 `唇色` 与 `肤质` |
| "再来十条不一样的" | 换 `--seed`，或换姿态 + 场景 + 服装组合 |
| "太露了" | `--leg mild` 或 `--leg none` |
| "换成宫廷风" | 整条重跑 `--tone 宫廷`，不在原 prompt 上打补丁 |
| "换个袖子" | `combo --sleeve 凤凰羽袖` 锁该槽，其余照抽 |
| "配色太艳" | 换同调性里更冷的配色（如 赤红与乌金 → 青灰与白玉） |

## 输出纪律

- 提示词正文**纯中文连续文本块**，不带 Markdown、不带换行分段、不带 `masterpiece, best quality` 这类英文尾巴
- 单条时给【选中元素】拆解便于用户微调（`--pick`）；批量时省略
- 不解释"我为什么这么选"，直接给词。用户要的是能生图的 prompt，不是创作说明

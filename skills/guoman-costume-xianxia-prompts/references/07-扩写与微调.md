# 扩写与微调

脚本产出的骨架是**合格线**，不是上限。用户要更长的段落、更强的画面感时，按本文件扩写。

---

## 一、扩写五法

### 1. 材质显影

标签写「雪纺」，扩写成「雪纺薄得能看见底下的轮廓，光一照就泛起一层雾」。

**原则**：把材质翻译成**光与触感**，不是形容词堆砌。

### 2. 结构落到身体

标签写「高腰束带」，扩写成「束带压在肋骨下方，把腰线掐出来，往上是一段收紧的背」。

**原则**：服装结构必须**挂到具体身体位置**，否则是悬空的。

### 3. 纹样给动态

标签写「凤凰纹刺绣」，扩写成「凤凰纹顺着肩线往上走，到锁骨处收成一只回首的鸟」。

**原则**：纹样要有**走向与终点**。

### 4. 配饰给光

标签写「银色流苏」，扩写成「流苏一动，碎光就跟着在颈侧跳一下」。

**原则**：金属与珠玉要**反光**。

### 5. 场景给气味与温度

标签写「雨后竹林」，扩写成「竹叶上的水还没干，风一过就有股青涩的草木腥气扑上来」——注意，「青涩」是禁词，改用「生涩的草木腥气」。

**原则**：场景必须有**至少一种非视觉感官**（气味 / 温度 / 触感）。

---

## 二、扩写三原则

1. **不加新元素**，只把已有元素写透。加元素会导致模型抓不住重点。
2. **不超原骨架的两倍**。骨架 350 字，扩到 700 字是上限。再长模型会丢后半段。
3. **段落内不重复用词**。同一个材质/颜色在一段里只点一次。

---

## 三、扩写的反面清单

| 反模式 | 为什么不行 | 改成 |
|--------|-----------|------|
| 「她美得不可方物」 | 空转形容词，模型无法执行 | 写具体特征：「眉骨高，眼尾挑起」 |
| 「气质出尘」 | 抽象 | 「站着不动，衣摆还在自己飘」 |
| 「如同仙女下凡」 | 陈词 | 直接写仙女该有的具体元素 |
| 「令人窒息的美」 | 主观评价，不是视觉信息 | 删掉，换成视觉细节 |
| 「宛如一幅画」 | 元描述 | 删掉 |
| 「绝美」「惊艳」连用三次 | 边际递减 | 一次足够 |

---

## 四、字数基准

| 线 | 骨架字数 | 扩写上限 | 适用 |
|----|---------|---------|------|
| 线 D（纯服装） | 70-100 | 180 | 服装设定图 |
| 线 C（立绘，5 句） | 280-360 | 600 | 默认 |
| 线 C（立绘，6 句） | 350-450 | 700 | 需要更多细节时 |

31 条范例实测：min 179 / max 472 / 均 353 字，5 句为主（19/31）。

线 D 比旧版短 —— 词库只剩七槽，没有上装/配饰/鞋履/边饰可写，硬拉长会变成形容词堆砌。

## 五、微调响应

| 用户说 | 改什么 | 怎么改 |
|--------|--------|--------|
| 场景换成海边 | 只换场景 + 光影 | 在 `tone_profile.py` 的 `SCENE_BASE` 加「海边」，并在 `LIGHT_OVERRIDE` 补**五个调性 × 海边**的光影（缺格会回落成「柔和自然光」，可能与场景矛盾） |
| 妆容淡一点 | 只换唇色 + 肤质 | 唇色往「裸色/自然」调，肤质往「匀净」调 |
| 再来十条不一样的 | 换 seed | `--seed` 换一个数；或换姿态 + 场景 + 服装组合 |
| 太露了 | 降露腿级别 | `--leg mild` 或 `--leg none` |
| 换成宫廷风 | 整条重跑 | `--tone 宫廷`，不在原 prompt 上打补丁 |
| 换个袖子 | 锁单个槽位 | `combo --sleeve 凤凰羽袖`，其余七槽照抽 |
| 换个配色 | 锁配色槽 | `combo --color 墨黑与暗金` |
| 加个武器 | 加道具分句 | 在 S4 后补一句「{手持/背负}{武器}」，武器不占七槽 |
| 换个发型 | 只换发式 | 从 `HAIR_STYLE_LONG` / `HAIR_STYLE_SHORT` 换，**注意长短句配套** |
| 颜色太艳 | 换配色 | 换成同调性里更冷的配色（如 赤红与乌金 → 青灰与白玉） |
| 要更性感 | 升 `--leg bold` + 换材质 | 材质换薄纱类，肩部换不对称设计 |
| 加配饰/鞋子 | **做不到** | 词库没有配饰/鞋履分类，只能在人物层加颈饰、头饰 |

## 六、模型链建议

本 skill 只产出提示词文本，不绑定具体模型。但按调性给两条参考：

| 调性 | 推荐尺寸 | 备注 |
|------|---------|------|
| 仙侠 / 宫廷 | 832×1216 或 1024×1536 | 竖构图，留出衣摆空间 |
| 战斗 / 暗黑 | 1024×1536 | 竖构图，强调轮廓光 |
| 新中式 | 896×1152 | 比例稍宽，适合现代构图 |

负面提示词通用：`九宫格, 渔网, 丝袜, 水印, 文字, 低分辨率, 多余手指`。

## 七、输出格式

### 单条（带拆解）

```
【选中元素】
  风格标签: 东方暗黑风格
  姿态: 以单手托腮的姿态半坐于画面右侧
  ...

【完整提示词】
一位东方暗黑风格的绝美年轻女子以单手托腮的姿态半坐于画面右侧，她眼神幽深而慵懒地直视镜头……
```

### 批量（纯正文）

```
1. 一位东方仙侠风格的……

2. 一位东方宫廷风格的……
```

**不带【选中元素】块**，方便直接复制。

# 禁词与质检（生成后必须过一遍）

本文件是提交前的最后一道闸。三类检查：**禁词**、**拼接病句**、**调性冲突**。

自动化实现：`scripts/selfcheck.py`。

---

## 一、全风格禁词（出现即违规）

```
九宫格 · 渔网 · 丝袜 · 青涩 · 大波浪发型 · 机顶直闪 · 皮肤白皙细腻如瓷
```

| 禁词 | 为什么禁 | 替换写法 |
|------|---------|---------|
| 九宫格 | 出图会跑成拼图 | 直接删 |
| 渔网 | 跑成渔网袜，且是廉价感 | 需要网状质感时写「镂空网状」 |
| 丝袜 | 触发平台审核 + 廉价感 | 需要包裹感时写「薄纱长袜」 |
| 青涩 | 未成年暗示，硬红线 | 改「年轻」「清爽」 |
| 大波浪发型 | 模型会锁死这个发型 | 直接写发式，如「长卷发披散至肩后」 |
| 机顶直闪 | 过曝，画面崩 | 需要硬光时写「硬质直射光」 |
| 皮肤白皙细腻如瓷 | 范例高频词，但已判定禁用 | 「肤若凝脂，肌肤细腻透亮」 |

**腿部专用规则**：形容腿时禁 `白皙`。

| 违规 | 正确 |
|------|------|
| 修长白皙的双腿 | 修长的双腿 |
| 修长白皙双腿 | 修长双腿 |
| 露出白皙的大腿 | 露出大腿 |

## 二、拼接病句（词库自带的坑）

这些是词库原文的合法表达，但**直接拼装**会出病句。脚本 `CLUNK_PATTERNS` 全部拦截。

| 病句模式 | 正则 | 原因 | 正确做法 |
|---------|------|------|---------|
| 配色配色 | `配色配色` | 槽值自带「配色」后缀 | 索引存裸词，渲染补一次 |
| 材质材质 | `材质材质` | 同上 | 同上 |
| 刺绣刺绣 | `刺绣刺绣` | 纹样槽补「刺绣」但词库原文已含 | 裸词 + 补一次 |
| 随动作垂落 | `(垂落\|垂坠)随动作垂落` | 袖型自带动词，又接了动词 | 袖型只并列 |
| 发色发式重复 | `的头发是.{1,6}色的，长直发` | 「她的头发是X色的」+「长直发…」 | 短句版发式去掉「长直发」前缀 |
| 缺句号粘连 | `[^。！？]轮廓[衣薄长裙披]` | 服装句尾没加句号就接动态 | 服装句以「。」收尾 |
| 采用+完整光影 | `采用(顶光\|夕阳\|云层\|灯笼光\|金柱)` | 光影词条本身是完整句，前面加「采用」成病句 | S5 直接接光影，不写「采用」 |

## 三、调性冲突

词库是中立零件池，装配时若不加约束会撞出不成立的组合。

### 3.1 服装冲突

服装只有七槽，调性冲突主要看配色与材质是否对得上调性。

| 调性 | 不该出现 | 原因 |
|------|---------|------|
| 仙侠 | 墨黑与暗金、紫黑与暗银 | 仙侠是浅冷调，深色重金会跑成暗黑 |
| 宫廷 | 冰晶纤维、玉石纤维 | 宫廷是织锦缎绒路线，纤维感材质违和 |
| 战斗 | 凤凰羽织物、月光纱、琉璃纱 | 战斗要利落，飘纱类会散架 |
| 暗黑 | 雪白与淡金、藕粉与珍珠白 | 暗黑是压暗调，浅粉白会跑成仙侠 |
| 新中式 | 凤凰羽织物、海水江崖纹 | 新中式是克制现代剪裁，重工古典纹样违和 |

### 3.2 气质冲突

| 调性 | 不该出现 | 原因 |
|------|---------|------|
| 暗黑 | 清澈而淡然、温柔而专注、明亮而松弛 | 暗黑不该是「清澈」的 |
| 战斗 | 慵懒而魅惑、疏离而平静 | 战斗要有攻击性 |
| 宫廷 | 带笑却不好惹、挑衅的锋芒 | 宫廷要威仪不要挑衅 |

### 3.3 场景 × 光影冲突

| 场景 | 禁止配的光影 | 原因 |
|------|-------------|------|
| 暗室 | 柔和自然光、均匀漫射光 | 「近乎无光」配「柔和自然光」自相矛盾 |
| 废墟 | 柔和梦幻侧逆光（暗黑调性下） | 废土感配梦幻光会跑成仙侠 |
| 夜市 | 均匀柔光配合大面积留白 | 夜市是强光源环境，留白不成立 |

## 四、年龄边界（硬边界，不可协商）

| 年龄段 | 身材描写 | 服装限制 | 露腿 |
|--------|---------|---------|------|
| < 18 | **零** | 限校服、衬衫、朴素裙装 | **禁止**，强制 `--leg none` |
| 18-24 | 可写曲线，克制的 1 句 | 常规 | 可露腿 |
| 25-30 | 放开写，1-2 个高频句 | 常规 | 可露腿 |

**未成年角色即使走暗黑/战斗调性，也强制 `--leg none` 且服装限朴素款。** 这条不因任何风格需求放宽。

## 五、跨条重复（批量专用）

单条合格不等于批量合格。100 条里 90 条用同一个句式，等于只写了 10 条。

### 5.1 三项去重铁律

| 层级 | 去重键 | 说明 |
|------|--------|------|
| 完整句 | 整条文本 | 完全相同即丢弃 |
| 三元组 | `(风格款, 场景, 姿态)` | 防止「同一件衣服同一姿势换个背景」 |
| 句式 | 第 2 句前 24 字 | 防跨条句式塌陷 |

### 5.2 重复率阈值

- 第 2 句重复率 **> 30% 即不合格**
- 实测：单变体时 71%（不合格），五变体轮换后 29%（合格）

### 5.3 自我重复

单条内部同一段 8 字以上文本出现两次，视为拼接事故。

## 六、自检清单（每批提交前逐条过）

- [ ] 无全风格禁词命中（`selfcheck.py` 自动查）
- [ ] 无「白皙」修饰腿
- [ ] 无拼接病句（配色配色 / 随动作垂落 / 足踏鞋扣）
- [ ] 调性无冲突（暗黑不配阳光明媚，战斗不配广袖）
- [ ] 未成年角色 `--leg none` 且服装朴素
- [ ] 批量时第 2 句重复率 < 30%
- [ ] 每条都有「精致的东方面容」或等价面部描写
- [ ] 结尾是场景+光影+氛围，不是问句

## 七、一键质检

```bash
python scripts/selfcheck.py out.txt --strict
```

输出示例（合格）：

```
[句式] 第2句重复 29/100 = 29%
[条目] 100 条
[PASS] 禁词 / 病句 / 调性 / 重复 全部通过
```

输出示例（不合格）：

```
[FAIL] 29 项问题：
  - #12 拼接病句：鞋履槽位取到了饰件/纹样而非鞋型
  - #62 调性冲突：暗黑 出现「阳光明媚」
  - 跨条句式重复率过高 71%（阈值 30%）
```

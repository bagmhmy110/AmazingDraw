# 七槽装配与六句骨架（执行层 · 每次生成前必读）

本文件是整个 skill 的装配说明书。线 D 用七槽，线 C 用六句，两者共用同一套服装词条。

---

## 零、零件现状（必须先理解这个）

服装有**两套零件**。

### 第一套：七槽骨架（主词库）

`01-服装词库-1100条.txt`，1100 条组合词，号段 0424-1523，每条固定七槽、逗号分句。

```
0424. [组合词] 青黛与银白配色，真丝材质，星辰纹刺绣，蝴蝶袖，鱼尾长裙，丝绸腰带，凤凰肩饰
```

逐槽词值数：配色 20 · 材质 30 · 纹样 30 · 袖型 30 · 裙装结构 30 · 腰部 30 · 肩部 30。

索引存两份：`slot_values`（带后缀，词库原样）与 `slot_bare`（剥掉后缀的裸词）。调性池用裸词，渲染时统一补后缀。

### 第二套：范例结构层（从 31 条范例抽取）

`02-仙侠范例31条.txt` → `scripts/example_lexicon.py`，10 层 109 条去重组件。

| 层 | 作用 | 范例里的存在感 |
|----|------|--------------|
| 上装结构 | 深V低胸 / 交领紧身 / 紧身胸甲 | 26/31 条有 |
| 肩部 | 龙鳞状护肩 / 羽翼状护肩 / 露肩 | 7 种 |
| 装饰纹样 | 金属浮雕花纹 / 晶体刺绣 / 璎珞 | 15 种 |

**为什么需要第二套**：光有七槽，服装句是空的 —— 没有上装结构、没有护肩、没有额饰耳饰、没有光感收尾。范例层补的正是这些。

### 两套的关系

| 槽位 | 用哪套 |
|------|--------|
| 配色 / 材质 / 纹样 / 袖型 / 裙装结构 / 腰部 | **七槽** |
| 肩部 | **范例层**（七槽的「肩部」是花瓣肩饰/云肩类装饰，范例层是龙鳞护肩类护甲，两回事） |
| 上装 / 装饰 / 腰饰 / 配饰 / 光感 | **范例层** |
| 头饰 / 额饰 / 耳饰 / 颈饰 | **范例层**（进 S3） |

## 一、线 D：七槽装配公式

```
{配色}，{材质}，{纹样}，{袖型}，{裙装结构}，{腰部}，{肩部}
```

**槽位顺序是固定的**，与词库组合词的逗号分句一一对应。脚本按此顺序拆解与重组，见 `assets/lexicon.json` 的 `slot_vocab`。

### 1.1 线 D 的输出骨架

```
东方{tone}风格女性角色服装设计。
{裙装结构}，上身为{上装结构}，{配色}配色，{材质}材质，
胸前与肩部装饰{装饰纹样}与{护肩}，{纹样}刺绣沿着衣缘蔓延。
{袖型}，{腰饰}束住腰线，{腰部}压住整体轮廓，
{配饰}在光里点出冷亮的一笔，{光感收束}。
高级感，电影级角色设计，收藏级国漫角色立绘，高精度服装细节
```

段落顺序对齐范例：上装+主裙 → 胸前肩部装饰 → 腰部 → 配饰 → 光感。尾部那句固定收，不要改。

### 1.2 指定单个槽位

用户点名某个元素时，只锁那一槽，其余照抽：

```bash
python scripts/promptforge.py combo --sleeve 凤凰羽袖 --color 墨黑与暗金
```

槽值支持模糊匹配（`--sleeve 凤凰` 会命中「凤凰羽袖」），匹配不到会报错并提示可用值。

范例层的组件（上装/护肩/装饰/配饰/光感）目前不支持命令行锁定，只能改 `example_lexicon.py` 的池子。

## 二、线 C：六句骨架

31 条仙侠范例（`02-仙侠范例31条.txt`）解剖后，稳定结构是 **5-6 句、283-472 字**（均 353 字）。句数分布：4 句 ×2、5 句 ×17、6 句 ×11、7 句 ×1。

### 2.1 骨架

| 句 | 内容 | 句式 |
|----|------|------|
| S1 | 风格 + 人物 + 姿态 + 眼神 + 气质 | `一位{风格标签}的{人物修饰}{姿态}，她{眼神}，{气质}。` |
| S2 | 面部 + 肤质 + 眉眼 + 瞳色 + 唇色 | 见 §2.2，**必须换序** |
| S3 | 发色 + 发式 + 头饰 + 额饰 + 耳饰 + 颈饰 | 见 §2.3，**四层叠加** |
| S4 | 服装（风格款 + 两层零件 + 动态 + 腿部） | `身着{风格款}。{服装句}。{动态}。{腿部}。` |
| S5 | 场景 + 光线 + 氛围 | `背景为{场景}，{光线}，营造出{氛围}氛围。` |

### 2.3 S3 的发饰密度（范例特征）

范例里发饰是四层叠加，这是「华丽感」的主要来源，不要简化成一层：

```
{发色}色{发式}，头顶佩戴{头饰}，{额饰}，耳畔垂挂{耳饰}，{颈饰}。
```

实例：

> 深黑色长发高高盘成古典发髻，头顶佩戴华丽金色凤冠，额前点缀精致金色细链饰物，耳畔垂挂长款金色与珍珠流苏耳坠，颈部佩戴厚重金色镂空颈环。

**注意**：颈饰词条有的自带「颈部佩戴」前缀，有的不带（如「厚重金色镂空颈环」）。渲染时统一补引导词，否则会出现「…，厚重金色镂空颈环。」这种断句。

### 2.2 S2 的五个变体（防跨条重复）

范例里这一句几乎全是同一个语序，批量产出会撞成一片。必须轮换：

```
1. 女子拥有{面部}，{修饰串}，{唇}
2. 她有一张{面部}，{修饰串}，{唇}
3. 她的脸是{面部}，{修饰串}，{唇}
4. 面孔是{面部}，{修饰串}，{唇}
5. 这张{面部}上，{修饰串}，{唇}
```

其中「修饰串」= 肤质 / 眉眼 / 眼眸 三项随机换序，「唇」在头或在尾各 50%。

**关键约束**：`{面部}` 是名词性中心语（「精致清冷的东方面容」），只能出现在「拥有/有一张/是」之后，**不能插进修饰串中间**，否则会出现「她有一张肌肤细腻…的面容」这种病句。

### 2.3 S1 与 S5 的变体

S1 固定，不要动 —— 它是整条的锚点，读者靠它判断调性。

S5 两套：

```
A. 背景为{场景}，{光线}，营造出{氛围}氛围。
B. 场景落在{场景}，{光线}擦过轮廓，整张画面是{氛围}的调子。
```

注意 A 版不要写「采用{光线}」—— 光影词条本身已是完整描述（「柔和梦幻侧逆光」「顶光从正上方垂直落下」），前面加「采用」会变成病句。

### 2.4 范例的句式基因（学结构，不抄措辞）

31 条范例的共性，可直接迁移：

- **S1 必带「一位…风格的」开头**，风格标签是调性的唯一显式信号
- **姿态用「以X姿态」或「优雅地侧坐」**，前者更通用
- **眼神固定为「X而Y地直视/望向镜头」**，形容词成对出现
- **气质固定为「唇角微抿/微扬带着X的气质」**
- **S3 发饰密度极高**：冠 + 镶嵌 + 额前 + 耳畔，四层叠加
- **S5 氛围是三形容词并列**：「优雅、性感且充满仙气的古典仙女氛围」

**但范例里有两个必须避开的坑**（见 `06-禁词与质检.md`）：

1. `皮肤白皙细腻如瓷` 出现 22/31 次 —— 这是禁词，改写为「肤若凝脂，肌肤细腻透亮」
2. `修长白皙的双腿` —— 「白皙」修饰腿是禁词，改写为「修长双腿」

## 三、拼接禁忌（词库自带的坑）

这一节是本 skill 踩过的所有坑，**照做，不要重新踩**。

| 坑 | 症状 | 原因 | 正确写法 |
|----|------|------|---------|
| 后缀重复 | 「月白与银灰配色配色」 | 槽值自带「配色」，拼装时又补了一次 | 索引存裸词，渲染时只补一次 |
| 后缀重复 | 「真丝材质材质」 | 同上，材质槽 | 同上 |
| 后缀重复 | 「祥云纹刺绣刺绣」 | 纹样槽要补「刺绣」，但词库原文已含 | 裸词 + 补一次「刺绣」 |
| 双动词 | 「垂坠长袖垂落」 | 袖型词条自带「垂坠」，又接了「垂落」 | 袖型含垂坠/层叠/飘/展开时不加动词 |
| 腰饰撞槽 | 「复杂腰封束住腰线，精致腰封压住轮廓」 | 范例层腰饰与七槽腰部都是腰封 | 两者同类型时只用腰饰替代 |
| 浮雕 ×3 | 「金属浮雕花纹 + 金属浮雕护肩 + 丝绸与金属」 | 装饰/护肩/光感三处都带浮雕与金属 | 装饰含浮雕→护肩避开；含金属→光感避开 |
| 「身着」重复 | 「身着X。身着Y，上身为…」 | 风格款与服装句各带一次 | 服装句开头不写「身着」 |
| 双句号 | 「…的光泽。。衣袂飘动。」 | 服装句已自带句号，S4 又补一个 | 检测结尾再补 |
| 发式重复 | 「红棕色的头发长发半挽」 | 「她的头发是X色的」+「长发半挽」 | 短句版发式要去掉「长直发/长发」前缀 |
| 场景撞调性 | 暗黑 + 「阳光明媚的庭院」 | 场景描述自带情绪形容词 | 场景本体中性，情绪按调性注入前缀 |
| 光影不搭 | 仙侠 + 「戏剧性顶光」 | 光影没跟调性联动 | 按 `(调性, 场景)` 查 `LIGHT_OVERRIDE` |
| 采用+光影 | 「采用顶光从正上方垂直落下」 | 长句光影本身完整，加「采用」成病句 | 短名词才接「采用」/「擦过轮廓」 |
| 动态撞服装 | 「丝绸自然垂坠」接「衣料垂坠…」 | 动态词条与服装句重复 | 脚本检测 `dyn in costume` 后自动换词 |

## 四、露腿分级

| 级别 | 写法池 | 适用 |
|------|--------|------|
| `none` | 完全不写腿 | 宫廷正装、保守需求、未成年角色（强制） |
| `mild` | 「衣料垂坠的走向勾勒出修长双腿的线条」/「裙裾下露出修长双腿的轮廓」/「长裙贴着小腿垂下，腿线清晰」/「裙摆垂到脚踝，走起来露出小腿线条」 | 默认 |
| `bold` | 「裙摆高开叉至大腿根部，露出修长双腿」/「高开叉的裙摆从胯侧一路开到腿根，整条腿露在外面」/「裙摆斜开一道高衩，大腿线条一览无余」 | 明确要求性感时 |

**`mild` 也要换着写**，否则一百条里九十条同一句。

## 五、人物层与服装层的边界

| 层 | 内容 | 来源 |
|----|------|------|
| 服装层 | 七槽（配色/材质/纹样/袖型/裙装/腰部/肩部） | **词库** |
| 人物层 | 面部 / 肤质 / 眉眼 / 眼眸 / 唇色 / 发色 / 发式 / 头饰 / 颈饰 / 姿态 / 眼神 / 气质 | skill 写作层 |
